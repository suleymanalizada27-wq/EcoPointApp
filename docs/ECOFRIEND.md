# EcoFriend mascot

Official name: **EcoFriend**. Assets: `assets/ecofriend/` (animated WebP, 512x512, ~20 fps,
transparent) and `assets/ecofriend/still/` (static PNG per mood). The originals were
VP9 WebM with alpha; they were converted to animated WebP because Flutter cannot play
alpha WebM without an extra package.

* `lib/features/ecofriend/domain/ecofriend_engine.dart` - pure-Dart state engine (priority,
  de-duplication, cool-down, auto-return to resting mood) + `widgetMoodAt`.
* `lib/features/ecofriend/application/ecofriend_controller.dart` - Riverpod controller, the single
  source of truth (Dashboard, scanner, widgets). Reacts only to backend-confirmed data; it never
  writes EP.
* `lib/features/ecofriend/presentation/ecofriend_view.dart` - `EcoFriendView`, `EcoFriendCard`
  (Dashboard), `EcoFriendHint` (static, empty/error states).
* Android widgets: `tool/android_res/widget/` (2x2, 4x2, 4x4 use static PNG; animated WebP is not
  supported by RemoteViews). Run `. .\tool\android_widget.ps1` to install.
* Widget quick links (4x4) reuse the quick_actions intent handled in `ShortcutsHost`.
* Tests: `test/ecofriend_engine_test.dart`.

## Duolingo-style presence (v4b)
* Dashboard hero: large animated mascot + speech bubble, tap the mascot for tips.
* `EcoFriendBanner` (mascot + bubble) on Missions, Statistics, Rewards, Bins, History, Guide,
  Referral, Profile; scanner has a live bubble; `EcoFriendCelebrationHost` (in `MainShell`)
  slides EcoFriend up on every tab for excited / cheering / proud.
* Widgets: light/dark palette (`ep_widget_colors*.xml`), chunky cards, speech bubble, week-dot
  row and big action buttons on the 4x4.

## v4c
* `EcoFriendView`: pop-in on every mood change, tap = jump + sparkles (cosmetic only).
* Full-screen confetti party (big EcoFriend) for cheering / proud; excited = bottom toast.
* Streak milestones (3, 7, 14, 30, 60, 100, 365) -> proud with `ef_streak`.
* More screens: onboarding (3 moods), sign-in, sign-up, settings, transfer, my QR, achievements.
* Widget: morning / evening nudge until the app is opened today.

## v4d (widget look)
Gradient card with 3D bottom lip + gloss, soft glow behind EcoFriend, speech bubble with lip,
glossy green "Scan" button, orange week coins; separate light / dark palettes.

## v4e (time-of-day widget scenes)
`ep_widget_bg_{morning,day,evening,night}.xml` (sky gradient, sun/moon, clouds, stars, hills);
Kotlin picks the scene by local hour (05-09 / 10-15 / 16-19 / 20-04); update period 30 min.

## v5 — EcoFriend 2.0 (premium mascot experience)
**Widgets (4x4 / 4x2 / 2x2, plus 3x2 and 2x1 restyled)**
* Pre-rendered scene art (RemoteViews cannot draw gradients/glows): `tool/gen_widget_art.py` →
  `art/ep_w_bg_{morning,day,evening,night}_{sq,wide}.webp` and `ecofriend/ecofriend_w_*.png`
  (original EcoFriend untouched; only soft shadow, light tint and accessories are added: sunrise
  sparkle, leaves, evening stars, sleepy Zzz, confetti, golden stars, a gentle heart for "welcome back").
* Layouts are generated by `tool/gen_widget_layouts.py` (FrameLayout/LinearLayout/TextView/ImageView only).
  Frosted panels: white by day, dark glass at night (tone chosen in Kotlin).
* Scenes: 05–09 morning (peach/sun), 10–15 day (mint/green), 16–19 evening (purple/pink/orange),
  20–04 night (navy/emerald, moon, stars, fireflies). Each scene has its own EcoFriend pose,
  decorations and message pool — not just a different background.
* Refresh: no polling. One inexact alarm (`setAndAllowWhileIdle`, no permission) per boundary
  (00, 03, 05, 06, 09, 10, 12, 15, 16, 18, 20, 21 h), re-armed after each tick; `updatePeriodMillis`
  is a 3 h safety net; the app pushes data on every balance / goal / streak change.
* Events (backend-confirmed excited / cheering / proud) override the scene; ≥ 7 days away → gentle "sad".
* Yesterday's daily goal is never shown as today's (`daily_day` stamp → goal resets natively).

**Smart messages** — `lib/features/ecofriend/domain/ecofriend_messages.dart` (pure Dart, tested)
* Inputs (all real data): time of day, daily-goal %, streak, opened-today, last confirmed recycle,
  level progress, new account, days away.
* Urgent states (streak at risk 16–22 h, goal ≥ 80 %, comeback after 3–6 days, first scan) come first;
  state messages are interleaved with the scene greeting. Rotation = day × 3-hour slot, so it changes
  every 3 h and never repeats back to back. `efm_*` keys exist in all 16 languages.
* The app writes one pre-translated pool per scene to the widget (`ef_pool_<scene>`); Kotlin only rotates.

**In-app**
* Dashboard card: larger EcoFriend, scene-tinted card, real message, EP / goal / streak / level chips,
  sleepy Zzz at night, follows the clock while open.
* Offline: EcoFriend "thinking" in the banner and error view (`ef_offline`); other errors: calm
  `ef_error`. More empty states now show EcoFriend (history, rewards history, bins, leaderboard, stats).

Install widgets: `. .\tool\android_widget.ps1` (copies layouts, drawables, art, PNGs, Kotlin; idempotent).
Regenerate art/layouts: `python3 tool/gen_widget_art.py && python3 tool/gen_widget_layouts.py`.
